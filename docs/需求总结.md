# AcademicTranslate Agent — 需求总结

## 一句话定义

在尽可能保持原 PDF 视觉版式与学术结构的前提下，对正文进行专业、可校验的翻译，并确保术语、公式、图表、引用、数值不被错误改写。

## 核心约束

1. **版面保真（Layout Fidelity）**  
   保持页面、双栏、章节、图片、公式、表格、图注关系高度一致；文字区域允许中文自适应重排。  
   **不承诺**像素级坐标 100% 一致。

2. **内容保真（Content Fidelity）**  
   公式 / 数字 / 单位 / 引用编号 / Fig·Table 编号 / DOI / 型号等进入保护区，程序化比对。

3. **Agent 化质量闭环**  
   翻译 → 术语检查 → 保真检查 → 结构检查 → QA Review → 失败回译。

4. **开放可配置大模型**  
   OpenAI 兼容协议，支持 GPT / Qwen / 本地网关等。

## MVP 已实现范围

- PDF 上传与 Layout 解析（PyMuPDF）
- 保护区识别与段落翻译 Agent
- 三层 QA（数值/单位/公式/引用/术语/漏译）
- 基于原稿的译文 PDF 合成
- Web：首页上传、翻译工作台、术语库、模型配置、历史
- 段落级人工修改 / 重新翻译 / 文档问答

## 明确延后

- 高精度双栏阅读顺序重建
- 公式 LaTeX/OCR 级还原
- 向量库 RAG
- 分布式任务队列
