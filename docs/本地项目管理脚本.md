# 本地环境项目管理脚本

面向 Windows 本地开发：一键 **初始化 / 启动 / 状态查看 / 停止 / 重启** 前端与后端。

## 需求摘要

| 能力 | 说明 |
| --- | --- |
| 启动 | 后台拉起后端（FastAPI/uvicorn:8080）与前端（Vite:5173） |
| 状态 | 查看 PID、端口占用、HTTP 健康检查 |
| 停止 | 按 PID 树杀进程，并清理端口占用 |
| 重启 | stop → start |
| 初始化 | 创建 `.venv`、装依赖、复制 `.env`、`npm install` |

## 快速使用

在项目根目录执行：

```bat
manage.bat setup
manage.bat start
manage.bat status
manage.bat stop
manage.bat restart
```

或 PowerShell：

```powershell
.\scripts\manage.ps1 setup
.\scripts\manage.ps1 start
.\scripts\manage.ps1 status
.\scripts\manage.ps1 stop
.\scripts\manage.ps1 restart
```

只操作一端：

```bat
manage.bat start backend
manage.bat stop frontend
manage.bat restart backend
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manage.bat` / `scripts/manage.ps1` | 统一入口 |
| `start.bat` / `scripts/start.ps1` | 启动 |
| `stop.bat` / `scripts/stop.ps1` | 停止 |
| `status.bat` / `scripts/status.ps1` | 状态 |
| `restart.bat` / `scripts/restart.ps1` | 重启 |
| `scripts/setup.ps1` | 首次环境初始化 |
| `scripts/common.ps1` | 公共逻辑（端口/PID/健康检查） |

## 运行时文件

脚本会在 `.runtime/` 写入：

- `backend.pid` / `frontend.pid`
- `backend.log` / `frontend.log`

该目录已加入 `.gitignore`。

## 默认端口

- 后端：`http://127.0.0.1:8080`（健康检查 `/api/health`）
- 前端：`http://127.0.0.1:5173`

与 `backend/.env`、`frontend/vite.config.ts` 保持一致。

## 常见问题

1. **提示找不到 venv / node_modules**  
   先执行 `manage.bat setup`。

2. **端口被占用**  
   先 `manage.bat stop`；若仍占用，用 `status` 查看 listening pids 后手动结束，或改端口配置。

3. **PowerShell 执行策略限制**  
   bat 入口已使用 `-ExecutionPolicy Bypass`，一般可直接双击/命令行运行。
